\section{Architecture}

\subsection{Durable history and canonical representation}
\code{qta\_agent/events.py} implements append-only, hash-chained history; \code{canonical.py} defines a canonical byte representation for records. The design intent is simple: a lost in-memory projection costs time, not authority. State can be rebuilt from durable history.

\subsection{Live projection and authority transitions}
\code{store.py} maintains the current projection. \code{authority.py} defines explicit transition rules instead of allowing arbitrary state mutation. Core invariants include:

\begin{table}[htbp]
\centering
\small
\begin{tabularx}{\linewidth}{@{}>{\bfseries}p{0.30\linewidth}X@{}}
\toprule
Invariant & Meaning \\
\midrule
Promotion requires verification & A proposed record cannot become canonical merely because it exists.\\
Revoked/rejected is terminal & Withdrawn authority is not silently resurrected; recovery creates a new record.\\
Stale cannot jump to promoted & Changed dependencies require renewed verification.\\
Proposer and verifier differ & Self-verification is refused at the authority layer.\\
Policy cannot retroactively bless & Later policy does not rewrite the legitimacy of an earlier decision.\\
Evidence must resolve & A syntactically valid digest is insufficient if matching bytes do not exist.\\
\bottomrule
\end{tabularx}
\end{table}

\subsection{Evidence and invalidation}
\code{evidence.py} stores evidence by content digest and re-hashes reads rather than trusting path layout. \code{invalidation.py} propagates the consequences of changed dependencies so stale authority is represented explicitly.

\section{Memory, context, evidence, and authority}

Agent systems often collapse several concepts into a single ``memory'' store. This harness keeps them structurally separate because their trust semantics differ.

\begin{table}[htbp]
\centering
\small
\begin{tabularx}{\linewidth}{@{}p{0.16\linewidth}p{0.27\linewidth}X@{}}
\toprule
Object & What it represents & What it does \emph{not} imply \\
\midrule
Context & What an agent was shown for a decision & That the displayed material is true or canonical\\
Memory & Durable remembered state reconstructed from lifecycle events & That a remembered statement is scientific evidence\\
Evidence & Byte-addressed material that resolves to a digest & That the scientific interpretation is correct\\
Authority & Whether a record is canonical under history, policy, and evidence & That the underlying scientific model has been experimentally validated\\
\bottomrule
\end{tabularx}
\end{table}

\code{context.py} records what was presented to an agent. \code{memory.py} gives remembered objects durable identities and lifecycle transitions. Retraction is meaningful: replay must not let a later forged event resurrect a terminally retracted memory by trusting payload state. This makes context compaction survivable because the authoritative history and memory projection live outside the model context.
