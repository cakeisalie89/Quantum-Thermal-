\begin{abstract}
AI agents can now write scientific code, invoke solvers, retain memory, coordinate work, modify assumptions, and operate for long sequences of actions. Those capabilities do not make the resulting scientific process trustworthy. Model context is transient; agent-reported state is self-authored; evidence can become stale after upstream changes; execution can be environment-dependent; and a process that both produces and certifies a result collapses computation and verification into the same authority domain.

This paper presents the \textbf{Scientific AI Harness}, an external execution, state, evidence, memory, policy, and verification substrate for long-horizon scientific agents. The central design decision is that the model is \textbf{not the system of record}. Durable history is append-only and hash-chained; current state is reconstructed from that history; evidence is content-addressed and re-hashed on read; memory, context, evidence, and authority are distinct objects; proposal, execution, verification, and promotion are separate operations; and side effects require explicit capabilities instead of ambient process privilege. A second implementation independently reconstructs governed state so the primary reader is not the only component capable of judging its own history.

The verifier is treated as an attack surface. Mutation testing, property-based testing, hostile replay, fuzzing, crash recovery, long-horizon campaigns, differential reconstruction, and cross-environment CI are used to ask whether weakening an enforcement point would actually be detected. The architecture grew out of QTA, a difficult cryogenic multiphysics project whose strict claim boundaries exposed a more general problem: long-running scientific automation needs an authority layer outside itself. QTA remains forecast-only with zero physical PASS gates and is used here as a stress workload, not as evidence that the harness can establish scientific truth.
\end{abstract}
