# QTA Glossary

MODEL-ONLY / FORECAST-ONLY. Zero PASS.

**Modes A/B/C/D** — Baseline; Carbon-13 Methane Processing; Isolation/
Recovery; Helium-3/Helium-4 NV Sensing. B and D never overlap; methane is
live only in B; helium only in D; H2 is residual/background, never live.
**Canonical output** — a root-level governed file, enumerated in
`final_manifest.json`, regenerated byte-identically by the default pipeline
and byte-gated by checker Step 2b. **Authority** — the single executable
definition of a concept (`authorities.json`). **Gate** — one row of
`results_gate_table.csv` (83 total); statuses CONDITIONAL / BLOCKED /
UNKNOWN / DERIVED_CHECK; **PASS is permanently zero** and `can_PASS_now=NO`.
**DERIVED_CHECK** — a numerical self-consistency result, never a physical
validation. **Coupling-ledger statuses** — IMPLEMENTED / REDUCED_ORDER /
BOUNDED_FORECAST / SCAFFOLD / NOT_IMPLEMENTED (see PHYSICS_INVENTORY.md for
the mapping to the inventory vocabulary). **FSM** — the 32-state
operational controller (`machine_fsm.py`); **IL-xx** — interlock ids
(IL-01..14 canonical, FSM-IL-15..18). **Kapitza sink** — radiative-form
boundary alpha_K*(T^4 - T_b^4), ASSUMED coefficient. **tau_c** — NV bath
correlation time; canonical 292 us (SNR=5 definition); 27.728 us is
SUPERSEDED. **EIG** — expected information gain (experimental-design
layer). **TRAINED_NOT_TRUSTED** — the deep layer's fail-closed status.
**Forecast-only** — every number is a model prediction under stated
assumptions; nothing is measured in this system.
